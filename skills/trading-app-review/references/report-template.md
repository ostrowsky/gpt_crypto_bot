# Report Template

## Executive Verdict

- One-paragraph summary.
- State whether the reviewed app is ahead, behind, or simply optimized for a different objective.

## What The Reviewed App Does Better

For each item:
- `Finding`
- `Why it matters`
- `Metric impact`
- `Transferability`

## Where The Reviewed App Is Weaker

Use the same structure.

## Compared With My Bot

Create a compact table:

| Axis | Reviewed app | My bot | Verdict |
| --- | --- | --- | --- |

## Compared With Professional SOTA

State:
- where the reviewed app matches current best practice;
- where my bot matches current best practice;
- where both lag.

## Gap Analysis

Split into:
- `Capability gaps`
- `Metric gaps`
- `Architecture gaps`
- `Research-process gaps`

## Roadmap For My Bot

Use three horizons:
- `Now`
- `Next`
- `Later`

For each action include:
- expected metric impact;
- dependency;
- backtest needed;
- adoption risk.

## What Must Be Backtested Before Adoption

List hypotheses in priority order.
