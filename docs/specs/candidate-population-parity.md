# Maximum candidate population parity

2026-10-02. TH-01..TH-12. Research-only, no BUY/SELL or release changes.

Compare every candidate generated by frozen batch replay against independently
rebuilt closed-prefix streaming inputs for champion and candidate, on the exact
maximum archive bounds and complete eligible population. Warmup is streamed before
the scored interval; restart/checkpoint serialization preserves temporal state.
Each frame exposes only candles whose close is at or before that frame. Repeat
the last closed row as a non-executable sentinel because the shared builder
ignores its last row. Recompute indicators from the prefix, not full-history
features sliced after computation. Compare all candidate fields and multiplicity,
not only executed BUYs or aggregate counts. Report frame/candidate denominators,
first mismatch, per-frame differences and immutable source/model/archive hashes.

An execution-only replay or two identical supplied snapshots cannot establish
candidate generation parity. This tool exercises the shared replay generator in
batch and prospective modes; it does NOT prove equivalence to monitor._poll_coin,
historical point-in-time universe membership, portfolio alpha or holdout quality.
Even PASS is explicitly not a full-policy validation certificate and cannot
authorize canary/promotion. Missing inputs or source drift yield UNKNOWN; genuine
candidate differences yield FAIL. Preserve rejected evidence. No production
success proofs are synthesized.

Tests: closed-prefix/sentinel causality, duplicate and score differences, empty
frames/zero denominator, warmup chronology, serialization, mismatched timestamps,
maximum-bound selection and evidence drift. Execute on the maximum frozen archive
without shortening the interval to obtain a pass. Runtime results are not Git
artifacts. Rollback: stop this read-only verifier; champion remains unchanged.
